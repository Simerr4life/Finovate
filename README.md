# Finovate
A python-based app that helps you budget, track and take control of your finances while letting you invest spare change into the stock market. Created for Hacklanta 2026

## Run the app

Finovate currently has a dependency-free Python UI skeleton. With Python 3 installed, run:

```sh
python app.py
```

Then open [http://127.0.0.1:8000](http://127.0.0.1:8000). The dashboard is the starting page; use the navigation to preview the Login, Investing, Savings, Budgeting, and Settings placeholders. The landing page is intentionally left untouched. These pages are static previews and do not store financial data or provide authentication.
